# Sample Test

Use the server and client codes in this folder and run wireshark in the background to capture sample packets for testing this application.

### Order:
 1. Run Wireshark
 2. Run tcp_server.py (in a new terminal)
 3. Run tcp_client.py (in a new terminal)

Note:
No need to convert you message into hexadecimal, the code will directly convert string into hexadecimal bytes string.
